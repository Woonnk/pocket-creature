# Pocket Creature 0.10.0 — public beta

Window perching and editable personal memory join the desktop dragon companion.

- He can sit on a restored window's top edge and follow its movement/resize. Leave room above the window, drag him away for a break, or drop him near the edge to choose a spot.
- Tell him clear personal details, or edit nickname, favorite games, interests, likes, and dislikes in Settings → Personal memory. Saving edits and forgetting clear the recent conversation to keep old preferences from lingering.
- Game corners, quiet mode, reduced motion, short speech bubbles, existing progress, and local Ollama use are preserved.
- GitHub documentation, screenshots, MIT license, contributor/report templates, CI, Windows packaging checks, and checksums are included for this public beta and the future stable 1.0 release.

Quit an older version from its tray before launching the portable Windows executable. No installation or account is required by the companion; optional Ollama/model installation is separate. The executable is unsigned.

Automated logic and browser checks use native/model mocks. Direct Windows perching, mixed-DPI monitors, exclusive fullscreen visibility, and live Ollama wording remain pending. See QA.md. Screenshots in the README are labeled browser playground previews.
